# Optimize the lossless cold-context tier

Evolve `choose_archive_tier(state, options) -> option_id`. The content-addressed
store is a protected oracle: evidence may leave inline text only after every
byte is secured behind an exact retrieval address. `visual_cold` is a redundant
recall aid, never the source of truth, and is admissible only for image-capable
hosts at a compaction boundary after quiet-needle and code-structure holdouts
pass for a measured provider. Secrets, unknown providers, insufficient image
budgets, and incomplete evidence must fail closed. Change only the
`EVOLVE-BLOCK`.
