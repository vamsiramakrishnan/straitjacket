Straitjacket · how it works

Capture once. Retrieve the line that matters.

Straitjacket captures a command's output on disk and gives the coding agent a short digest, with an address for what it left out. Scroll to follow the log from its own benchmark through it: 20,001 lines, one of which matters.

01 / The flood

One command puts 20,001 lines in the prompt

02 / Residency

The expensive byte is the one that survives

The command ran once. Its output goes back to the model with every later request, until the host compacts the conversation. Over the next six turns the same 302,628 tokens are sent six more times.

03 / The fixes that did not hold

Cut the middle and the line goes with it

Keeping only the first and last 40 lines brings the output down to 1,219 tokens. Line 14,238 is not among them. A filter for ERROR keeps the two loud lines and misses this one, because it is an INFO line. Both results are small. Neither can give the line back.

04 / The insight

Evidence and prompt need different lifetimes

Evidence should remain complete for as long as policy retains it. The prompt should contain only the facts needed for the current decision. An address connects the two.

active context + addresses → complete evidence on demand

05 / Capture

Captured once, before it reaches the model

Run the same command through ctx. It executes with your permissions and writes stdout and stderr to a local store. A profile that knows the format sorts what it captured: 11 templates cover all 20,001 lines. By default the digest is computed locally, with no model call.

$ ctx run -- cat corpus.log
[ctx run:8956c843e556 profile=logtemplate/v1]
stdout: 20,001 lines · 979.1 KiB

07 / Retrieval

The omission has an address

19,988 lines stayed out of the prompt. They are still in the store. The handle names the run and a selector names the lines, so the agent can ask for exactly what the next decision needs. A read that would be too large comes back as a narrower view with a continuation.

$ ctx get run:8956c843e556#stdout --lines 14238:14238
L14238: INFO worker-14 checkout request req-14237 fell back to legacy gateway after circuit opened

1 lineasked for by address when the decision needs it

The example on the documentation's home page. The receipt checks that the address is emitted; it does not run the round trip. See docs/CONCEPTS.md

08 / Residency, contained

Keep the conclusion resident. Page in evidence when a decision needs it.

The same seven turns now carry the 531-token digest. When turn four needs the surrounding lines, it fetches 21 of them. The log itself never becomes part of the conversation.

09 / Anchors

An address should name content, not a position

Agents edit the files they cite. After an edit, a line number points at whatever now sits there. An anchored address carries a short hash of the content it names. Resolving it verifies the text, follows it if it moved, or refuses.

10 / Handoff

Hand over the address, not the conversation

One worker finds the failing line. The next one needs that fact, not the transcript that led to it. A worker passes a failing test, a source location, or a verified patch as an address, and the task ledger records each attempt and handoff so a resumed route can reuse finished work. Your harness still runs the model, authenticates the user, and controls its tools.

Works alongside Claude Code, Codex, Antigravity, Hermes, Oh My Pi, OpenCode and DeepSeek Harness.

12 / Receipts

Receipts before spectacle

Every measured figure on this page comes from a receipt checked into the repository, and the seven-turn trace is marked as illustrative. Some of the results are not flattering. Small, complete native results may be cheaper and easier to use. Straitjacket is for when access to what was left out matters.

13 / Try it

Try it on a failing test

In a repository with a pytest suite, run:

python -m pip install 'ctx-harness==0.5.0'
ctx run -- pytest -q

For a long failure, ctx returns the test names, a digest, and an address for the captured output. To connect your coding harness, run ctx setup and then ctx doctor.
