## How it works

Complete tool output stays in the artifact store. Model context carries a bounded view and stable addresses. Retrieval reconnects the two when more detail is required.

## Core guarantees

<CardGrid>
  <Card title="Bounded output">
    Digest size is constrained independently of the original payload size. Small complete results may pass through unchanged.
  </Card>
  <Card title="Reversible omission">
    Omitted evidence retains a stable address. `ctx get` and `ctx search` recover exact stored regions without rerunning the operation.
  </Card>
  <Card title="Deterministic rendering">
    Equivalent evidence under the same contract produces stable model-visible bytes.
  </Card>
  <Card title="Declared coverage">
    A digest states what it parsed, showed, and omitted. Short output is not treated as success when required identities disappear.
  </Card>
</CardGrid>

## Current trust boundary

Straitjacket provides output containment, bounded retrieval, repository-relative path controls, traversal and symlink checks, timeouts, process-group handling, and deterministic rendering.

It is not yet a general process sandbox. Commands run with the authority of the invoking user. Separate-identity execution and capability-authorized handles remain a distinct planned boundary.
