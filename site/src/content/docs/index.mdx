## Start with a task

| Task | How to do it |
|---|---|
| Hand a code review from one harness to another | [Configure an ACP worker](/straitjacket/guides/acp/). [Preview the route](/straitjacket/guides/routing/) to see which harness and model gets each step. Workers pass checkpoints and evidence addresses to their dependents. |
| Decide which skills a model sees | [Inspect the capability surface](/straitjacket/design/capability-surface/). On Claude Code, compare the estimated cost of a skill listing with its deferred body and choose a launch profile. |
| Trace a symbol across a repository | [Search for the definition and follow its references](/straitjacket/guides/use-cases/). Open the reported span when you need the implementation. |
| Keep a repeated prompt prefix cacheable | [Put fixed reference material before the changing evidence and question](/straitjacket/guides/query-aware-selection/). Compare provider-reported cache usage and total task cost. |
| Run Gemini 4 Hydrogen, Neon, Carbon, or Argon | [Select a model for Antigravity](/straitjacket/guides/native-agy-sessions/). Run `agy models` for your account's native IDs. ACP uses its endpoint's advertised ID. |

## Capture a failure

In a Python repository with tests:

```sh
python -m pip install --upgrade ctx-harness
ctx run -- pytest -q
```

For a long test run, the agent gets the outcome, failed test names, and an
address for the captured output. A failed test run returns a nonzero status. Replace the sample
handle below with the address from your digest.

```sh
ctx search run:ba3d1020ee8f#stdout 'AssertionError'
```

The CLI requires Python 3.11+. Host hooks are optional. The local plaintext
store retains up to the configured capture limit. [Follow one command through capture and retrieval](/straitjacket/start/how-it-works/).

## What the benchmarks tell you

A 20,001-line fixture used 302,628 tokens as raw text. Its 531-token digest
retained the quiet event at line 14,238 and a retrieval address. In a separate
live comparison on three small tasks, both agents solved all three and the
wrapped agent cost more. Use task completion and provider usage to decide
where wrapping pays. [Log fixture](https://github.com/vamsiramakrishnan/straitjacket/blob/main/evals/field-needle-2026-07-20.md) ·
