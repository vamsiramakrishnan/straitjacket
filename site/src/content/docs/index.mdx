straitjacket is a local context-containment harness for coding agents. On
supported paths, it captures potentially unbounded command output before it
enters the conversation, stores the complete bytes locally, and returns a
bounded digest with routes back to the stored evidence.

## Why it exists

Large test runs, build logs, searches, and diagnostics create a bad choice.

Keep the complete output in the conversation, and every later model turn can
carry it. Truncate it, and the missing line cannot be recovered. A larger
context window postpones the limit, but it does not make old output useful on
every turn.

straitjacket separates the evidence from the view of the evidence.

- The artifact store keeps the complete output.
- The prompt keeps the outcome, useful facts, coverage, and retrieval
  addresses.
- The agent asks for bounded regions only when the next decision needs them.

## Try it

```bash
python -m pip install --upgrade ctx-harness  # Python 3.11+
cd your-repository
ctx setup
ctx doctor
ctx run -- pytest -q
```

The package is `ctx-harness`. The command is `ctx`.

Small results can pass through unchanged. A large result becomes a typed digest
instead of a wall of output. The complete stdout and stderr remain available:

```bash
ctx get run:8d8335db6848#stdout --lines 120:180
ctx search run:8d8335db6848#stdout "MissingTenantError"
ctx diff run:8d8335db6848 run:5a67c9de0123
```

Retrieval is bounded too. Asking for a large region returns a smaller view and
a continuation instead of creating a second flood.

## What it gives developers

### Noisy commands without noisy conversations

Run test suites, builds, linters, and logs through `ctx run`. straitjacket
stores the raw streams and renders a deterministic digest for the output
family.

### Evidence you can inspect

A digest declares what it saw, what it omitted, and where the omitted bytes
live. Frozen run handles address immutable stored bytes while retained. The
model-visible view remains bounded and subject to the current redaction policy;
an exact-byte request declares when redaction changed it. Live repository
addresses verify their content, relocate it when it moves, or refuse when it no
longer exists.

### Fewer avoidable model round trips

Use `ctx seq`, `ctx q`, or an evidence plan when several deterministic checks
are already known. The work runs beside the repository. The model returns when
new evidence can change the hypothesis.

### Integration with the agent you already use

`ctx setup` detects Claude Code, Codex, and Antigravity. It merges JSON settings
where safe, refreshes ctx-managed files and blocks, and prints a reviewed
snippet instead of rewriting user-owned Codex TOML. Enforcement depends on the
host; the boundary is stated below.

## How it works

1. A guard identifies an operation that may produce unbounded output.
2. stdout and stderr stream into a local, content-addressed artifact.
3. A typed profile extracts outcomes, identities, locations, and coverage.
4. A deterministic renderer emits those facts within a fixed budget, with
   continuations into the stored artifact.

There is no model call in this delivery path. The digest is an index into the
evidence, not a generated summary pretending to be the evidence.

## One reproducible receipt

The repository includes a deterministic test built from a 20,001-line log. The
log contains 302,628 `o200k_base` tokens, one structurally rare target at line
14,238, and two loud `ERROR` controls.

| Treatment | `o200k_base` output tokens | Quiet target retained | Retrieval address emitted |
|---|---:|:---:|:---:|
| Complete log | 302,628 | Yes | Not applicable |
| Head-and-tail truncation | 1,219 | No | No |
| straitjacket | 531 | Yes | Yes |

This measures the evidence-delivery mechanism. It is model-free and does not
claim that every coding task becomes faster or cheaper. The fixture checks that
the digest emits an address; it does not execute a retrieval round trip. The
live agent suite also records cases where native execution is the better path.

## Where it helps

| Work | Start with |
|---|---|
| Noisy test, build, lint, or log output | `ctx run -- <command>` |
| A process that may outlive the turn | `ctx run --bg-after 30 -- <command>` |
| Search or retrieve captured evidence | `ctx search` or `ctx get` |
| Compare behaviour before and after a change | `ctx diff run:A run:B` |
| Run known checks without model round trips | `ctx seq` or `ctx q` |
| Map or navigate a large repository | `ctx map`, `ctx def`, `ctx refs` |

If a command is already small and complete, run it natively. Containment should
not turn a six-line answer into a retrieval workflow.

## The current boundary

straitjacket is pre-1.0. Its contract is narrower than “agent memory” or “agent
security.”

- It contains tool evidence. It is not a process sandbox. Commands still run
  with the invoking user's authority.
- Claude Code can transparently rewrite predictable floods and replace
  oversized results. The Codex path implements and contract-tests both gates,
  but a live Codex CLI receipt is still pending.
- Antigravity can deny a predictable flood and provide the bounded replacement
  command, but its published hooks cannot replace a returned tool result.
- Run handles address immutable stored bytes while the artifact is retained;
  model-visible retrieval is bounded and subject to the current redaction
  policy. Mutable repository content may move or disappear, so anchored reads
  verify, relocate, or refuse.
- Captured artifacts can contain source, logs, and secrets. They are stored as
  local plaintext today. Thirty days is the default GC eligibility horizon;
  artifacts remain until `ctx gc` runs. An explicit `--retention-days` value
  can shorten the horizon, while pins and active checkpoint leases survive.
- Small or already-bounded work may be faster without the harness. That regime
  is tested rather than hidden.
