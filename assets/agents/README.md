# Coding-agent marks

These marks identify the integrations listed in the capability matrix. They
are not Straitjacket branding and do not imply endorsement or equal support.
Names and marks belong to their respective owners. Retrieved 2026-09-06.

| File | Source |
|---|---|
| `claude.svg` | [ACP registry, Claude adapter](https://github.com/agentclientprotocol/registry/blob/main/claude-acp/icon.svg) |
| `codex.svg` | [ACP registry, Codex adapter](https://github.com/agentclientprotocol/registry/blob/main/codex-acp/icon.svg) |
| `antigravity.png` | [Google Antigravity press assets](https://antigravity.google/press), full-color icon |
| `hermes.svg` | [Hermes documentation favicon](https://github.com/NousResearch/hermes-agent/blob/main/website/static/img/favicon.svg) |
| `omp.svg` | [OMP project favicon](https://github.com/can1357/oh-my-pi/blob/main/packages/collab-web/public/favicon.svg) |
| `opencode.svg` | [OpenCode app favicon](https://github.com/anomalyco/opencode/blob/dev/packages/app/public/favicon.svg) |
| `dsh.svg` | [DSH documentation favicon](https://github.com/deepseek-ai/deepseek-harness/blob/master/website/public/favicon.svg) |

Claude, Codex, and Hermes receive only a light/dark foreground style; paths
and glyphs are unchanged. Other files retain their upstream bytes, apart from
a trailing newline on text assets. The docs build copies these local files to
its public directory, so rendering does not depend on a third-party image CDN.
